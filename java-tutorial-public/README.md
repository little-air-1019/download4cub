# Java 教學系列

這是一系列針對 Java 初學者整理的教學文章，內容涵蓋日常開發中最常用、也最容易混淆的三大主題：

| # | 主題 | 檔案 |
|---|------|------|
| 01 | Java Collections Framework：從 Array 到 Map 的選擇邏輯 | [01-java-collections-framework.md](./01-java-collections-framework.md) |
| 02 | Java Exception：寫出健壯程式的錯誤處理之道 | [02-java-exception.md](./02-java-exception.md) |
| 03 | Java JDBC 入門：從連線到交易的實戰筆記 | [03-java-jdbc.md](./03-java-jdbc.md) |

## 風格說明

這個系列定位為「會了之後，回頭來跟大家分享」的整理筆記。內容會盡量：

- 用直觀的方式說明每個觀念的「為什麼」
- 補充實務上會踩到的坑
- 提供完整、可執行的程式碼範例

文章預計發布於 Medium 與 IT 邦幫忙等平台。如果你在閱讀時發現任何錯誤、或覺得有可以補充的地方，歡迎透過 issue 或留言回饋。

## 文章閱讀順序

三篇文章彼此獨立，可以單篇閱讀；但如果想完整理解 Java 在「資料處理」這條主線上的全貌，建議按順序：

1. **Collections** — 在記憶體中怎麼管理一群資料
2. **Exception** — 程式出錯時怎麼優雅地處理
3. **JDBC** — 把資料和外部資料庫接起來

從「記憶體內 → 錯誤處理 → 對外溝通」的三層次，是日常 Java 後端開發的基本功。
